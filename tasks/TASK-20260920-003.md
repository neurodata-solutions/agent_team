# TASK-20260920-003

## Objetivo

Corrigir deploy do jaaz após dois incidentes reais em produção durante a sessão: crash-loop por regex de env-var errado, e queda de DNS interno (postiz-postgres/jaaz) por perda de network alias ao reconectar rede manualmente

## Resultado

Dois incidentes de produção nesta sessão, ambos causados pelo próprio coordenador ao tentar aplicar os fixes acima: (1) regex de extração de env-vars (^(INFISICAL_|X)=) só batia com o prefixo exato, perdendo 5 de 7 variáveis — container subiu sem INFISICAL_API_URL e crashou em loop; corrigido com regex correto + contagem obrigatória antes de docker run. (2) docker network connect sem --alias recriou as 3 redes do container sem o apelido DNS 'jaaz' (só 'opensuite-jaaz' ficou), quebrando resolução de 'jaaz' a partir do renderer (getaddrinfo ENOTFOUND jaaz, toda renderização de vídeo falhando) e 'postiz-postgres'/'infisical-backend' a partir do jaaz; corrigido reconectando as 3 redes com --alias jaaz --alias opensuite-jaaz. As 6 lições viraram checklist obrigatório em TEAM_CONTRACT.md (seção 'Checklist de deploy de container').

## Evidências

- docker exec opensuite-jaaz getent hosts postiz-postgres/infisical-backend/timeline-studio-mcp -> resolvido
- docker exec opensuite-openshorts-renderer getent hosts jaaz -> resolvido
- curl localhost:57988/ -> HTTP 200 após cada correção
